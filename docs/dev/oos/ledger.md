## 说明：为什么 v1 和 v2 结论差这么多

```
v1 的 ④ 要求「层4 > 层2 > 层0」。
实测 6/6 因子的层收益曲线二次项 c < 0（鼓形：中间层最高），
且层1~层3 之间只差 1~3.5pp/年，落在噪声里 ⇒ ④ 检验的是一个没有功效、
且与数据类型方向相反的假设 ⇒ 系统性假阴性（4 个因子形状 12/12 全对却被判死）。
```

⇒ v1 的判决保留在表 A，不改写；v2 从 2026-11-13 起生效。
